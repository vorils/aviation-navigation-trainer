# aviation-navigation-trainer
Interactive aviation navigation trainer for UGR-4UK and NL-10M. Includes simulation and exam modes, responsive interfaces for desktop, tablet and mobile, realistic instrument interaction, navigation calculations, and local browser-based operation.

# Aviation Navigation Trainer

Interactive aviation navigation trainer for working with the **UGR-4UK** instrument and the **NL-10M** navigation slide rule.

The project is designed for training and knowledge assessment in a browser without requiring additional software or a server.

## Features

### UGR-4UK

The UGR-4UK module provides three training modes:

- **With readings** — instrument values are displayed on screen for easier learning.
- **Without readings** — the user must determine the instrument readings independently.
- **Exam** — 20 tasks without hints or displayed instrument values.

The simulator is based on interconnected navigation values such as:

- Magnetic Course — MK
- Relative Bearing — KUR
- Magnetic Bearing to Radio Station — MPR
- Magnetic Bearing from Radio Station — MPS
- Desired Course — ZK

Instrument indications are generated consistently according to the navigation calculations used in the trainer.

### NL-10M

The NL-10M module includes two modes:

- **Simulation** — interactive training with the navigation slide rule.
- **Exam** — 20 tasks without hints.

The simulator uses a realistic representation of the NL-10M and reproduces the basic principles of working with the navigation slide rule.

Available interaction includes:

- movement of the slide;
- independent movement of the cursor;
- switching between both sides of the NL-10M;
- horizontal scrolling on small screens;
- working with logarithmic scales;
- speed, time and distance calculations;
- use of the `60` and `36` indices.

## Responsive Interface

The website has responsive layouts for different device types:

- Desktop
- Tablet
- Mobile

The interface automatically adapts to the available screen size.

On mobile devices, controls are optimized for touch input, while the NL-10M remains horizontally scrollable instead of being compressed.

## Technology

The project is built with:

- HTML
- CSS
- JavaScript

No frameworks, backend or database are required.

The trainer can be launched locally directly in a browser.

## Launch

1. Download or clone the repository.
2. Open the project folder.
3. Launch `index.html` in a modern browser.

No installation is required.

## Purpose

The main goal of the project is to provide a simple and accessible training environment for practicing aviation navigation calculations and instrument reading skills.

The trainer can be used for:

- independent training;
- classroom demonstrations;
- preparation for practical exercises;
- knowledge assessment;
- exam preparation.

## Disclaimer

This project is intended for **educational and training purposes only**.

It should not be used as a certified navigation instrument or as a replacement for approved aviation training equipment, operational documentation, or official flight navigation procedures.
